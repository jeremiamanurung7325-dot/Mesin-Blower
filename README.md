# Simulasi Mesin 3D — Tsurumi TSR2-200

**Dikembangkan oleh Jeremi Manurung.**

Website simulasi pembelajaran rotary blower dengan:
- Visualisasi mesin 3D, eksplorasi komponen dan exploded view
- Animasi aliran udara serta penjelasan cara kerja
- Kontrol RPM edukatif dan grafik running dinamis
- Kurva performa berdasarkan tabel katalog Tsurumi TSR Series

## Website
Aktifkan GitHub Pages melalui **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.

Alamat website (setelah Pages aktif): https://jeremiamanurung7325-dot.github.io/Mesin-Blower/

## Catatan teknis
Simulasi ini **bukan** data sensor mesin nyata, CFD, model CAD fabrikasi atau panduan menentukan batas operasi. Performa dirujuk dari katalog *Tsurumi Roots Type Blowers TSR Series*, khusus model TSR2-200, dengan interpolasi dan asumsi ilustratif saat running. Identitas pembuat adalah atribusi proyek pembelajaran, bukan afiliasi resmi Tsurumi.

Foto dan video unit lapangan serta nomor seri mesin tidak disertakan dalam versi publik.
